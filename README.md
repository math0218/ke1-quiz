# 科目一 · 精简500题 刷题网站

纯静态单页应用，无需安装任何依赖。

## 使用

- 直接双击 `index.html` 用浏览器打开即可（Chrome / Safari / Edge 均可）。
- 或者在本目录起一个本地服务（手机同一 Wi-Fi 下也能访问）：

  ```bash
  cd ke1-quiz
  python3 -m http.server 8000
  # 浏览器打开 http://127.0.0.1:8000
  ```

## 功能

| 模式 | 说明 |
|------|------|
| 顺序练习 | 按题库顺序刷，自动记住上次位置 |
| 随机练习 | 全库乱序一遍，顺序保存在本地 |
| 错题集 | 选错的题自动收录；错题练习里答对后可点“已掌握”移出 |
| 全部题目 | 497 个题号色块（未做 / 答对 / 答错），点击跳转 |

- 选择答案后立即判对错，下方展开 **💡 技巧提示**（原书蓝色口诀，220 题有）和 **📖 解析**（每题都有）。
- 答对默认 1 秒后自动跳下一题（首页可关闭），答错停留。
- 键盘：`1`–`4` / `A`–`D` 选答案，`←` `→` 翻题，`Enter` 下一题。
- 进度与错题保存在浏览器 localStorage，首页可导出 / 导入 JSON 换设备用。

## 文件

```
index.html   页面骨架
style.css    样式
app.js       逻辑（路由、做题、错题集、存档）
data.js      题库：window.QUESTIONS = [{id,type,question,options,answer,image,tip,explanation}]
img/         150 张题图（交通标志、仪表、路况图等）
```

题库来源：《驾考精简500题电子版》（2023 年 2 月版）PDF，共 497 题（单选 249 / 判断 248）。
题干与选项经 OCR 识别并逐题人工复核；正确答案取自原截图中的蓝色勾选标记。
